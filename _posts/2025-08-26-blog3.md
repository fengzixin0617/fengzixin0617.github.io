Following the initial PR and multiple rounds of code review and revisions. The final code of FRLM models have been produced. 
The module now allows for flexible choices among different versions of the FRLM model, including the basic FRLM model, the threshold extension FRLM model, and the capacited FRLM model. 
Meanwhile, it also allows for flexible setting of different parameters when using the package. 

##  Model Types Overview

| Model Type |  Key Features | Computational Method |
|------------|--------------|---------------------|
| **Basic FRLM** | Maximise flow coverage with fixed number of facilities | Arc Cover Path Cover (AC-PC) or Combination-based approach|
| **FRLM Threshold Extension** |  Ensures minimum coverage per node | AC-PC Combination-based approach|
| **Capacitated FRLM** | Considers facility capacity constraints | Combination-based approach |

### Class Initialisation: `FRLM()`

| Parameter | Type | Default | Valid Range | Description | Model Applicability |
|-----------|------|---------|-------------|-------------|-------------------|
| `vehicle_range` | float/int | 200000 | (0, 1] or > 1 | • If 0 < value ≤ 1: Percentage of longest path<br>• If value > 1: Absolute distance in network units | All models |
| `p_facilities` | int | 5 | > 0 | Number of facility modules to locate | All models |
| `capacity` | float/None | None | > 0 or None | • None: Uncapacitated model<br>• float: Maximum capacity per facility module | Capacitated only |
| `threshold` | float | 0.0 | [0.0, 1.0] | Minimum flow coverage % for node coverage<br>• 0: Disables threshold extension | Threshold Extension |
| `weight` | float | 0.99 | [0.0, 1.0] | Trade-off parameter:<br>• 1.0: Prioritize node coverage<br>• 0.0: Prioritize flow coverage | Threshold Extension |
| `objective` | str | "flow" | "flow", "vmt" | • "flow": Maximize total flow coverage<br>• "vmt": Maximize vehicle miles traveled | All models |
| `include_destination` | bool | False | True/False | Include destination nodes in weight calculation | Threshold Extension |

## Method Parameters

### `add_flow()`
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `origin` | Any | Yes | Origin node ID |
| `destination` | Any | Yes | Destination node ID |
| `volume` | float | Yes | Flow volume between OD pair |
| `path` | List/None | No | Pre-computed path (auto-computed if None) |

### `solve()`
| Parameter | Type | Default | Valid Options | Description |
|-----------|------|---------|---------------|-------------|
| `solver` | str/pulp.LpSolver | None | "greedy", pulp solver instances | Solver selection |
| `seed` | int/None | None | Any integer | Random seed for greedy solver |
| `initialization_method` | str | "empty" | "empty", "random", "central", "high_flow" | Greedy initialization strategy |
| `max_iterations` | int | 100 | > 0 | Maximum iterations for greedy solver |
| `**kwargs` | dict | - | Various | Additional solver-specific parameters |

### `generate_path_refueling_combinations()`
| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `facility_combinations` | List[List]/None | None | Pre-computed facility combinations |
| `start` | int/None | 1 | Minimum combination size |
| `stop` | int/None | p_facilities | Maximum combination size |
| `method` | str | "auto" | "auto", "combination", "ac_pc" |
