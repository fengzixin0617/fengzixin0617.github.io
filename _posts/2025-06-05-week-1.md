Hi, I'm Zixin, I am a third-year PhD student in the Univeristy of Glasgow. In GSOC 2025, I will work on the development of Flow Refueling Location Models (FRLMs) for PYSAL. 

This project aims to extend PySAL's spatial optimiisation library (spopt) by implementing flow-based facility location models, specifically, the basic FRLM, threshold extention FRLM, Capacited FRLM, 
and Deviated FRLM.  For example, in the field of transport facility planning, facility loca8on models have evolved from nodes-based to flow-based approaches to better capture demand as traffic flows passing by a facility.

Before the start of the project, I already had the code for the basic FRLM but it was not in an OOP format. I was also not familiar with the process of open-source package development. To start, I familiarised myself with how to:

- Fork a repository
- Clone my forked repository to set up a local development environment
- Create branches for different features and bug fixes
- Commit changes and push changes to my fork on GitHub
- Create pull requests to propose changes to the main repository

After getting familiar with the workflow, I started refactoring my code into an object-oriented format. With help from my mentors, I’ve also picked up some open-source coding practices, which are quite different from how I used to code for my own research projects.

- __Code Simplification and Class Design__ At first, I had written separate classes for the capacitated and basic models, but my mentors suggested combining them into a single class. Instead of multiple classes, users can just set parameters to switch between model types. This makes the API cleaner and more intuitive. I also learned to be more thoughtful with default values. For example, using "200,000 neters" for a distance threshold or "10% of the longest path" for capacity limits gives users sensible starting points.

- __Code Quality and Pre-commit Hooks__  I also learned about pre-commit hooks. This keeps the code style consistent and catches formatting issues before anything gets pushed to the repo.
